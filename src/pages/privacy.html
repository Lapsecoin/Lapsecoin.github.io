Privacy policy

What LapseCoin and this website do with your data. Last updated 22 October 2026.

In short

  • LapseCoin has no accounts and the project does not collect your personal information. We cannot see your wallet, your balance or your keys.
  • Your wallet key, recovery phrase and passphrase stay on your device. They are never sent anywhere.
  • The LapseCoin network is public. Transactions and the blocks nodes build are visible to everyone, permanently.
  • The program has no analytics. It sends one thing without asking: a report when it crashes, with no names, folders or addresses in it, filed as a public GitHub issue (see Crash reports below). This website uses Google Analytics.
  • We do not sell data.

The LapseCoin program

LapseCoin is open source software that runs on your computer as a wallet and network node. The project runs no server that receives your data from the program. What the program does is below.

Stored on your device

Your wallet file, chain database, peer list and logs are kept in a folder on your computer (%USERPROFILE%\LapseCoin from version 1.1.6, %LOCALAPPDATA%\LapseCoin before). The wallet file is encrypted with your passphrase. We have no copy and cannot recover it for you. Keep your recovery phrase safe.

Visible to the network

  • Transactions: addresses, amounts and any memo you add are recorded on the public chain and cannot be removed.
  • Your IP address: a node connects to other nodes, so the peers you connect to can see your IP address, as in any peer-to-peer network.
  • Your CPU model: a node that builds blocks puts its CPU model in each block by default, and that becomes part of the public chain. You can turn this off in the settings, and the blocks then carry an opaque identifier that names no hardware.

Services the program may contact

  • GitHub (raw.githubusercontent.com) to check whether a newer version exists, and to download an update if you choose to install one. GitHub sees your IP address.
  • Public IP lookup services (api.ipify.org, icanhazip.com, checkip.amazonaws.com) when the node cannot learn its public address from its peers.
  • Public blockchain RPC providers and Relay (relay.link) for the features that pay or request network fees on other blockchains, including a check of an address against a public sanctions list. These services see the addresses involved and your IP address.

Each of these services has its own privacy policy. The program sends them only what the request itself needs.

Crash reports

From version 1.1.6, the program reports a critical crash by itself, so that it can be fixed without anyone having to ask you for files. This happens only when the program stops because of an error, at start-up or while it runs, or when Windows ends it for a fault (a crash in native code, or a file that would not load). In that case the small program that starts LapseCoin (lapsecoin-launch.exe, the one the Start menu uses) sends the report right after Windows ended it. Nothing is sent otherwise, and nothing is sent while the program runs normally.

What is sent

  • The error and where in the program it happened (a traceback), the last few start-up steps, and the crash entries Windows itself wrote for it (the file that failed, the error code).
  • The LapseCoin version, the Windows version and build number, the processor architecture and the Python version.

Before it is sent, these are taken out: your account and computer name, folder paths, LapseCoin addresses, keys and recovery phrases, any value written after a word like passphrase or key, long strings of hex or base64 text, IP addresses and e-mail addresses. Dates and times are replaced by the seconds between steps, so no time zone shows, and the command line is reduced to the names of its options without their values. The cleaning errs on the side of removing too much. Your wallet, keys, recovery phrase, passphrase, balance and transactions are not part of a report, and there is no identifier that could link two reports to the same person.

Where it goes

The program files it directly as an issue in the public LapseCoin issue tracker, labelled crash-report, one issue per kind of crash, with a short comment for each repeat. Anyone can read those issues. GitHub sees your IP address when the report is sent, as with any request to it, and handles it under its own privacy statement. The project does not run a server that receives these reports and does not keep your address.

Turning it off

Set the environment variable LAPSECOIN_CRASH_REPORTS to 0, or put an empty file named crash-reports-off in your data folder (%USERPROFILE%\LapseCoin). The program saves a crash report to a file there either way, so you can read exactly what it would send: lapsecoin-crash.log.

This website

The website is hosted on GitHub Pages, which keeps server logs under GitHub's privacy statement. The pages use Google Analytics to count visits. It sets cookies and records usage such as pages viewed, approximate location, browser and device type. You can block it with a browser extension or your browser's tracking settings, and the site works without it. The download page loads the list of releases from this site and links to GitHub for the files.

Your choices

Because we hold no personal data from the program, there is nothing for us to export or delete. Data on the public chain cannot be changed by anyone, so think before you put personal details in a memo. To keep your IP address from peers and the services above, run the program behind a VPN.

The program is not directed at children.

Changes and contact

If this policy changes, the date at the top changes with it, and the history is public in the site repository. Questions can go to us on Discord or as an issue on GitHub.
